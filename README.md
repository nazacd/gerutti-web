# gerutti-web

Сайт магазина мужской одежды **Gerutti** — MVP для показа клиенту.
Структура и интерактив сделаны по мотивам разбора `cerca-trova-rebuild-spec.md`, но в собственной айдентике Gerutti
(тёмно-синий и кремовый из логотипа).

## Что внутри

- Главная: hero-слайдер, мозаика оттенков, блок о бренде, карусель новинок.
- Каталог: фильтры по цвету и размеру, сортировка, вид 4 / 3 / 2 в ряд, карточки с перелистыванием фото.
- Карточка товара: галерея с миниатюрами и просмотром на весь экран, выбор цвета и размера, таблица размеров.
- Lookbook, избранное (хранится в браузере), поиск, контакты.
- Корзина и оформление заказа **временно отключены**: кнопка «В корзину» открывает сообщение
  «Онлайн-заказ скоро откроется».

Бэкенда, базы данных и админки нет — это статический сайт.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Адрес, телефон, часы работы, соцсети, валюта | `src/data/site.ts` |
| Товары, цены, размеры, описания | `src/data/products.ts` |
| Слайды на главной | `src/app/page.tsx` (массив `slides`) |
| Цвета и шрифты | `src/app/globals.css` (блок `@theme`) |

Контакты — реальные. Цены пока демо-значения, их нужно заменить.

## Фото и видео

Исходные фото лежат в `images/`. Скрипт выравнивает фон и сохраняет их в `public/media/`:

```bash
python3 scripts/build-media.py
```

Видео первого экрана — `public/media/hero.mp4` (горизонтальное) и `hero-mobile.mp4` (вертикальное для телефонов),
постеры — `hero-poster.webp` и `hero-mobile-poster.webp`. Чтобы заменить ролик, положите новые файлы с теми же именами
и поправьте `duration` (в миллисекундах) у первого слайда в `src/app/page.tsx`.

## Публикация

Сборка — статическая, результат в папке `out/`:

```bash
npm run build
```

**GitHub Pages.** В настройках репозитория: Settings → Pages → Source → «GitHub Actions».
После этого каждый push в `main` публикует сайт по адресу `https://<владелец>.github.io/gerutti-web/`.

**Vercel / свой домен.** Достаточно импортировать репозиторий — дополнительных настроек не нужно
(переменная `NEXT_PUBLIC_BASE_PATH` используется только для подпапки GitHub Pages).
